# UX仕様書（Phase 3：操作性・UI最適化 / Figmaライク）

* 対象：Chrome拡張の注釈Editor（キャプチャ→編集→PNG保存）
* 前提：Chromeタブ可視範囲キャプチャ＋可視範囲内の範囲指定、図形は枠線のみ、保存はPNG固定（Downloads直下、`YYYYMMDD_HHMMSS.png`）、個人利用
* 版：v0.9（Phase 3草案）

---

## 1. UX方針（Figmaライクの定義）

1. **Canvas中心**：主役はキャンバス。UIは周辺に退避し、編集の邪魔をしない。
2. **左：ツール / 右：インスペクタ**：操作の入口は左、詳細設定は右に集約。
3. **キーボードファースト**：主要動作（ツール切替、Undo/Redo、削除、ズーム）はショートカットで完結。
4. **コンテキストUI**：選択対象に応じて右パネルの項目が切り替わる（必要なものだけ出す）。
5. **一貫性**：色・線幅・文字サイズなどの操作方法を統一し、迷わせない。

---

## 2. 画面レイアウト仕様

### 2.1 画面構成

* **Top Bar（上部固定）**

  * 左：戻る（任意）/ 再キャプチャ（任意）
  * 中央：ファイル名（例：`20251219_143501`）
  * 右：Undo / Redo / Zoom（%）/ Export（保存）
* **Tool Rail（左：縦）**

  * Select / Rectangle / Ellipse / Arrow / Text
  * 各ボタンはアイコン＋ツールチップ（「Rectangle (R)」のようにショートカット表示）
* **Canvas（中央）**

  * 背景：薄グレー
  * 画像（スクショ）を「キャンバスカード」として表示（白背景＋薄い影）
* **Inspector（右：縦）**

  * 選択中オブジェクトに応じて表示項目を切替
  * 主要プロパティ：Stroke（色/幅）、Text（色/サイズ）

### 2.2 見た目（ガイド）

* 選択枠：青系 1px（例：#0D99FF系）
* ハンドル：四隅＋辺中点（MVP後なら四隅のみでも可。Phase 3で増やす）
* 余白：Canvas周囲は十分なマージン（ツールに触れずドラッグしやすい）

## 3. ツール仕様（挙動）

### 3.1 ツール一覧

* Select（選択/移動）
* Rectangle（矩形：枠線のみ）
* Ellipse（楕円：枠線のみ、Shiftで正円）
* Arrow（矢印：線＋矢印ヘッド）
* Text（テキスト）

### 3.2 共通ルール

* **作成時のデフォルトスタイル**はInspectorの「現在値」を適用（未選択時でも次に作るものへ反映）
* **選択中オブジェクトがある場合**、Inspectorの変更は原則そのオブジェクトへ即時反映
* Escで「作成中キャンセル」または「選択解除」
* Delete/Backspaceで削除

### 3.3 作成操作

* Rectangle/Ellipse/Arrow：

  * クリック＆ドラッグで作成
  * MouseUpで確定
* Text：

  * クリックでテキストボックス生成→即入力モード
  * クリック外で確定

### 3.4 修飾キー（Figma寄せ）

* **Shift**

  * Rectangle：正方形固定
  * Ellipse：正円固定
  * Arrow：水平/垂直/45度スナップ
* **Alt/Option（任意：Phase 3で導入）**

  * 図形：中心から拡大縮小（Figma感が強い）

---

## 4. ショートカット仕様

### 4.1 ツール切替（Figma寄せ）

* V：Select
* R：Rectangle
* O：Ellipse
* A：Arrow（Line系）
* T：Text

### 4.2 編集

* Delete / Backspace：削除
* Esc：キャンセル / 選択解除
* Ctrl/Cmd + Z：Undo
* Ctrl/Cmd + Shift + Z：Redo（併用で Ctrl/Cmd + Y も可）
* Ctrl/Cmd + C / V：コピー＆ペースト（Phase 3で可能なら追加）
* Ctrl/Cmd + +/-：ズーム
* Ctrl/Cmd + 0：フィット（任意）

※ブラウザ予約ショートカットと衝突する場合は、拡張側のcommandsは「キャプチャ起動」だけに限定し、Editor内はJSでハンドリングする。

---

## 5. インスペクタ仕様（右パネル）

### 5.1 表示ルール

* **未選択**：Defaults（次に作る要素のデフォルト）を表示
* **図形選択（Rect/Ellipse）**：Stroke Color / Stroke Width
* **矢印選択（Arrow）**：Stroke Color / Stroke Width / Arrow Head Size（任意）
* **テキスト選択（Text）**：Text Color / Font Size

### 5.2 項目定義（最小セット）

* Stroke

  * 色：スウォッチ10色＋Custom
  * 幅：数値（1〜20）＋スライダー（任意）
* Text

  * 色：スウォッチ10色＋Custom
  * サイズ：数値（8〜72）＋ステップボタン（任意）

## 6. 色（カラーピッカー）仕様

### 6.1 デフォルト：10色スウォッチ

* Inspector内に常時表示（Stroke/Text共通UI）
* クリックで即適用
* 初期デフォルト：注釈用途を想定し**赤**を選択状態にする

**スウォッチ例（仮）**

1. Red `#FF3B30`
2. Orange `#FF9500`
3. Yellow `#FFCC00`
4. Green `#34C759`
5. Cyan `#32ADE6`
6. Blue `#007AFF`
7. Purple `#AF52DE`
8. Pink `#FF2D55`
9. White `#FFFFFF`
10. Black `#000000`

### 6.2 Custom（無限色）

* スウォッチ横に「Custom…」ボタン（または＋）を配置
* Customダイアログで提供するもの

  * カラーピッカー（色相＋明度彩度）
  * 入力欄：HEX（必須）＋RGB（任意だが推奨）
* 入力はリアルタイムプレビュー、OKで確定

### 6.3 Recent（最近使った色）

* Customで確定した色はRecentに格納（最新5件）
* 次回起動でも保持（`chrome.storage`）
* スウォッチの近くに表示し、ワンクリック適用可能

## 7. 操作フロー（代表シナリオ）

### 7.1 可視範囲キャプチャ→編集→保存

1. 拡張起動（アイコン/ショートカット）
2. Editor表示（キャンバスにスクショ）
3. Rで矩形→赤枠作成、Lで矢印、Tでテキスト入力
4. Export押下→DownloadsにPNG保存（命名規則適用）

### 7.2 範囲指定キャプチャ→編集→保存

1. 「範囲指定キャプチャ」開始
2. 画面にオーバーレイ→ドラッグ選択→確定
3. Editor表示（切り抜き済み画像）
4. 注釈→保存

## 8. コピー（文言）・フィードバック

* 保存ボタン：**Export PNG** / **保存（PNG）**（どちらかに統一）
* トースト（画面右下など）

  * 「保存しました：20251219_143501.png」
  * 「キャンセルしました」
* エラー

  * 「キャプチャに失敗しました。タブを再読み込みして再試行してください。」

---

## 9. 例外・エッジケース

* 画像未ロード時：ツール操作を無効化しローディング表示
* Undo/Redo境界：スタックが空のときボタン無効
* テキスト空入力：確定時に空なら生成を破棄（不要オブジェクト抑制）
* 極小サイズ図形：一定以下（例 3px未満）は自動破棄または最小値へ丸め

---

## 10. 受け入れ条件（Given-When-Then）

* **ツール切替**

  * Given：Editor表示中
    When：`R`を押す
    Then：矩形ツールが有効になり、ツールボタンがアクティブ表示になる
* **正円作成**

  * Given：Ellipseツール中
    When：Shift押下しながらドラッグ
    Then：生成される楕円は正円になる
* **矢印スナップ**

  * Given：Arrowツール中
    When：Shift押下しながらドラッグ
    Then：矢印は水平/垂直/45度にスナップする
* **色選択（スウォッチ）**

  * Given：図形を選択中
    When：赤スウォッチをクリック
    Then：選択図形のStroke色が赤に変わる
* **Custom色**

  * Given：Textを選択中
    When：CustomでHEXを入力しOK
    Then：文字色が指定色に変わり、色はRecentに追加される
* **保存**

  * Given：注釈を追加済み
    When：Export押下
    Then：Downloads直下に`YYYYMMDD_HHMMSS.png`でPNGが保存される
