# 2) 要件定義書（改訂追記）

## 2.1 機能要件 追記

### F-014：マーカー（ハイライト）機能

* マーカーを自由描画（フリーハンド）で追加できること
* マーカーは **半透明** とし、背景画像・文字が透けて見えること
* マーカーの変更可能項目

  * 色（10色スウォッチ＋Custom＋Recent）
  * 太さ（例：4〜40）
  * 透明度（例：10%〜80%）
* マーカーは選択・移動・削除・Undo/Redo対象であること

### F-015：マーカーの描画補助（Figma寄せ）

* Shift押下中は、フリーハンドの角度を一定にする（任意：水平/垂直寄せ）
  ※初期は「実装しない」でも可。Phase 3の拡張項目として定義。

## 2.2 非機能要件 追記（性能）

* NFR-005：マーカー描画中に線が追従し、遅延・カクつきが顕著でないこと

  * 想定：一般的なPCで可視範囲スクショ（数千px幅）に対してリアルタイム描画が成立
* NFR-006：Undo/Redoが破綻しないこと（マーカー1ストローク単位）

## 2.3 前提・制約 追記

* マーカーは「塗り」ではなく **透明ストローク** で表現する（図形の塗りつぶしは導入しない）

# 5) 設計書（改訂追記）

## 5.1 注釈オブジェクトモデル 追記

### Marker（新規）

* `id: string`
* `type: "marker"`
* `points: Array<{x:number, y:number}>`  ※ストロークの軌跡
* `color: string`（HEX想定）
* `width: number`
* `opacity: number`（0.1〜0.8）
* `smoothing: boolean`（任意：true）
* `bbox: {x,y,w,h}`（選択・当たり判定用、作成時算出）

## 5.2 描画・合成順（重要：固定）

1. 背景画像（スクショ）
2. **マーカー（半透明）**
3. 図形（矩形/楕円/矢印：枠線）
4. テキスト

※これにより「ハイライトで下線/強調」らしい見え方になる。

## 5.3 Undo/Redo単位

* Markerは **1ストローク確定（MouseUp）** を1操作としてUndoに積む
* 移動・リサイズ・削除も従来通り操作単位で履歴化

## 5.4 選択・編集

* Markerの選択はbboxベース（まずは簡易）。必要なら「線との距離判定」に拡張。
* 移動はbbox選択→ストローク全点を平行移動
* リサイズはPhase 3以降（初期は「移動のみ」でも可。ただしUX仕様と整合させる）

## 5.5 パフォーマンス方針

* 描画中：

  * ポイント追加は一定間隔以上の移動時のみ（例：前点から2px以上）
  * requestAnimationFrameで描画更新
* 確定後：

  * pointsの間引き（任意）
  * 数が増えた場合は「マーカーレイヤーのみ」オフスクリーンCanvasに焼き付けてキャッシュ（任意）

# 6) UX仕様書（改訂版：マーカー追記）

## 6.1 ツールレール（左）追記

* 追加ツール：**Marker（マーカー）**
* ツール順（例）：Select / Rectangle / Ellipse / Arrow / **Marker** / Text
  ※「描く系（Arrow/Marker）」を並べると迷いが減る

## 6.2 ショートカット追記（Figma寄せ方針）

* 推奨：`M` をMarkerに割当（Markerの直感）

  * M：Marker
  * 既存：V/R/O/A/T
* マーカー中：

  * Esc：描画キャンセル
  * Shift：任意（水平/垂直寄せ）※導入する場合のみ

## 6.3 インスペクタ（右）追記：Marker選択時

* Marker設定

  * Color（10スウォッチ＋Custom＋Recent）
  * Width（4〜40、スライダー＋数値）
  * Opacity（10%〜80%、スライダー＋数値）
* 未選択時DefaultsにもMarkerのデフォルト値を含める（次回作成に効く）

## 6.4 操作仕様（Marker）

* Markerツール選択→キャンバス上でドラッグするとマーカーが描画される
* MouseUpで確定し、直後は選択状態になる（位置調整しやすくする）
* 透明度により背景が透ける（“塗りつぶし図形”ではない）

## 6.5 受け入れ条件（追記）

* Given：Markerツールが選択されている
  When：ドラッグして線を引きMouseUp
  Then：半透明のマーカーストロークが追加され、Undoで直前ストロークが消える
* Given：Markerが選択されている
  When：Opacityを変更
  Then：当該Markerの透明度が即時反映される
* Given：未選択状態
  When：Defaultsでマーカー色を青に変更→Markerを新規作成
  Then：新規Markerは青で作成される

# 7) 任意（推奨）：描画仕様補足（短い版）

この補足を入れると実装のブレが激減します。

* マーカーの合成：通常アルファ合成（opacity指定）を基本
* 線端：丸（round cap）、線結合：丸（round join）推奨（ハイライトらしい）
* アンチエイリアス：有効
* エクスポート時は上記合成順を厳守
